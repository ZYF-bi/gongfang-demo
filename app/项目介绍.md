# 小验工坊：一句话生成可运行网页

## 一、项目简介

小验工坊是一个 AI 网页生成工具。用户用中文描述想要的小工具，比如"一个番茄钟计时器，可设置时长"，AI 会生成一个可以直接运行的单页网页，并在页面右侧实时预览。之后可以接着提修改意见，让 AI 在现有网页上继续改；满意后保存到自己的账号，随时打开、再改或删除。

项目最早用 Next.js、TypeScript 和本地数据库开发，后来迁移到了 Atoms 平台。

- 线上地址：https://uveh2w.pub.atoms.world
- 适合人群：想快速做出小工具、演示页面或原型，但不想写代码的人。

## 二、核心功能

| 功能 | 说明 |
|------|------|
| 需求输入 | 用中文描述需求，最多 2000 字；页面提供示例需求，点击即可填入 |
| AI 生成网页 | 生成一个完整的单页 HTML，样式和脚本都写在页面里，不依赖任何外部资源 |
| 可视化预览 | 生成的网页放在隔离的预览窗口里运行；运行出错时，页面顶部会提示错误内容 |
| 继续修改 | 每次修改都会把原始需求、之前的修改记录和当前代码一起交给 AI，修改记录按顺序列出 |
| 保存项目 | 登录后可以保存项目，项目列表显示版本号和更新时间，可以打开、再改、删除 |
| 可调整布局 | 左侧操作区和右侧预览区之间可以拖动调整宽度，每一侧最窄占 1/3、最宽占 2/3，双击分隔条恢复默认；窄屏时两栏改为上下排列 |
| 账号登录 | 使用平台统一账号登录，每个用户只能看到自己的项目 |

## 三、使用流程

1. 打开网站，点击"登录"，用自己的账号登录或注册。
2. 在左侧输入框描述想要的网页，点击"生成网页"，一般需要 1 到 2 分钟。
3. 在右侧查看生成的网页，可以直接操作。
4. 想调整时，在左侧输入修改意见，点击"应用修改"。
5. 满意后点击"保存"，项目会出现在"我的项目"里。

## 四、技术架构

| 部分 | 技术 |
|------|------|
| 前端 | React、Vite、TypeScript、shadcn/ui、Tailwind CSS |
| 后端 | Atoms Cloud（FastAPI） |
| 数据库 | Atoms Cloud 数据库，项目存放在 `projects` 表 |
| 登录 | Atoms Cloud 自带的账号系统 |
| AI 模型 | claude-opus-4.6，单次最多输出 16000 个 token |

**生成流程：** 前端把需求发给后端生成接口 `/api/v1/workshop/generate`，后端先确认用户已登录，再调用 AI 模型。前端收到结果后，从中取出完整的 HTML，检查代码是否完整、大小是否在 200 KB 以内、有没有引用外部资源，通过后放进预览窗口运行。

**主要文件：**

- `frontend/src/pages/Index.tsx`：主页面，包括输入、预览、项目列表和拖动分栏
- `frontend/src/lib/workshop.ts`：给 AI 的提示词、HTML 检查、预览安全处理
- `backend/routers/workshop.py`：需要登录的生成接口
- `backend/models/projects.py`：项目的数据表结构

## 五、安全设计

- **必须登录才能生成：** 生成接口和平台自带的 AI 接口都要求登录，不登录调用会被拒绝，防止别人消耗 AI 额度。
- **用户数据隔离：** 每个用户只能读取、修改、删除自己的项目。
- **预览窗口隔离：** 生成的网页在限制很严的窗口里运行：只允许运行脚本，不能访问外部网络、外部资源和主页面，也不能跳转链接或提交表单。
- **输入和输出检查：** 需求长度、请求格式、生成结果的完整性和大小，都会先检查。

## 六、测试情况

| 测试项 | 结果 |
|--------|------|
| 不登录或用伪造凭证调用接口 | 通过，全部被拒绝 |
| 用户之间的数据隔离 | 通过，用户 B 看不到、也改不了、删不了用户 A 的项目 |
| 项目的新建、查看、修改、删除 | 通过 |
| 错误参数检查 | 通过，缺字段、内容为空、格式错误都会被拒绝 |
| 真实生成一个计时器 | 通过，约 11 秒返回，网页代码完整 |
| 20 个请求同时访问 | 有问题，本地测试 20 个中 7 个失败 |

**说明：** 这些是在本地用模拟的登录凭证测试接口得到的结果。用真实账号登录后，在页面上走完生成、保存等完整流程，还需要在线上确认。

## 七、已知限制和后续计划

- **同时访问的人多时：** 部分请求可能失败，原因是后端默认只有 1 个数据库连接。可以尝试在后端环境变量里调大 `DB_POOL_SIZE`，这个方法还没有在线上验证过。
- **生成次数没有限制：** 登录后每个人都可以不限次数生成，费用都算在发布者的 AI 额度上。原项目有"每人每小时 10 次、每天 30 次"的限制，这次还没迁移过来。
- **生成的网页不能长期保存数据：** 预览窗口不允许使用浏览器本地存储，网页里的数据刷新后就没了。这是原项目有意这样设计的。
- **后续计划：** 限制每人生成次数；导出或下载生成的网页；分享单个作品。
